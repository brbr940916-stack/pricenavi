PriceNavi 무료 테스트 배포 안내 (Render)
========================================

이 패키지는 기존 v15 Python 서버를 Render 무료 Web Service에서 시험 배포할 수 있도록 render.yaml을 추가한 버전입니다.

배포 순서
1. ZIP 압축을 풉니다.
2. GitHub에 새 비공개 저장소를 만듭니다.
3. 압축을 푼 폴더 안의 파일과 폴더를 저장소 최상위에 업로드합니다. render.yaml, Dockerfile, cloud_app.py가 최상위에 있어야 합니다.
4. https://dashboard.render.com/ 에 로그인하고 New > Blueprint를 선택합니다.
5. GitHub 저장소를 연결하고 render.yaml을 배포합니다.
6. 배포가 끝나면 Render가 제공하는 https://서비스이름.onrender.com 주소로 접속합니다.

무료 플랜의 중요한 제한
- 15분 동안 요청이 없으면 서비스가 잠들며, 다음 접속 때 약 1분 정도 깨어나는 시간이 걸릴 수 있습니다.
- 무료 인스턴스의 로컬 파일은 재시작, 재배포, 절전 후 초기화될 수 있습니다. 현재 앱은 SQLite를 사용하므로 가입 계정, 등록 상품, 가격 이력이 사라질 위험이 있습니다.
- 무료 플랜은 상시 실행되는 별도 Worker/Cron 작업을 지원하지 않습니다. 가격 자동 확인은 서비스가 실행 중일 때만 동작할 수 있고, 항상 정해진 주기로 실행된다고 보장할 수 없습니다.
- 따라서 이 배포는 화면과 기본 흐름을 확인하는 데 쓰는 테스트용입니다. 실제 고객을 받거나 중요한 데이터를 저장하는 운영 서비스로 사용하면 안 됩니다.
- SMTP 이메일, 토스 결제, 도메인 연결은 별도 계정/키/설정이 필요하며 이 파일에서 활성화하거나 검증하지 않았습니다.

무료 테스트에서 데이터 손실을 피하려면 실제 개인정보나 결제정보를 입력하지 마세요. 안정적인 운영 전에는 영구 저장소와 상시 실행 백그라운드 작업이 있는 유료 서버 또는 적절한 외부 데이터베이스/작업 큐 구조로 전환해야 합니다.
