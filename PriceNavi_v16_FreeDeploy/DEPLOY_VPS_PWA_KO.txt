가격 추적기 v15 - VPS 배포 및 PWA 설치 안내
============================================

1. 이 패키지는 Android/iPhone/PC에서 설치할 수 있는 PWA 웹앱입니다.
   APK/IPA 또는 앱스토어 등록본은 아닙니다. 실제 HTTPS 도메인 배포 후 설치할 수 있습니다.

2. 서버 준비
- Ubuntu 24.04 LTS 권장, Docker Engine 및 Docker Compose plugin 설치
- 방화벽: SSH(22)는 관리자 IP로 제한, HTTP(80)/HTTPS(443) 허용
- 도메인의 A 레코드를 서버 공인 IP로 연결
- 프로젝트 파일을 /opt/price-tracker 에 배치

3. 환경변수 설정
- cp .env.example .env
- APP_SECRET은 `openssl rand -hex 32` 결과로 설정합니다. 실제 APP_SECRET 이름을 사용합니다.
- DOMAIN=실제 도메인, PUBLIC_BASE_URL=https://실제 도메인
- ADMIN_EMAIL을 실제 관리자 이메일로 설정합니다.
- COOKIE_SECURE=true 유지
- SMTP/Toss 키는 각각 해당 사업자에서 발급받은 운영용 키를 넣습니다. 키가 없으면 해당 기능은 비활성/제한됩니다.
- .env는 외부에 공개하거나 Git에 커밋하지 마세요: chmod 600 .env

4. 배포 전 검사 및 실행
- python3 preflight_check.py .env
- 오류가 있으면 출력된 항목을 수정하고 재검사
- docker compose config
- docker compose up -d --build
- docker compose ps
- curl -fsS https://실제도메인/health
- 로그 확인: docker compose logs --tail=100 app caddy
- Caddy가 80/443으로 접근 가능하고 DNS가 맞으면 TLS 인증서를 자동 발급합니다.

5. 자동 백업
- compose는 ./backups 폴더를 컨테이너 /backups로 마운트합니다.
- 수동 백업: ./deploy/backup.sh
- Ubuntu systemd 자동 백업 설치:
  sudo cp deploy/price-tracker-backup.service /etc/systemd/system/
  sudo cp deploy/price-tracker-backup.timer /etc/systemd/system/
  sudo systemctl daemon-reload
  sudo systemctl enable --now price-tracker-backup.timer
  systemctl list-timers price-tracker-backup.timer
- 서비스 파일의 WorkingDirectory/ExecStart가 실제 설치 경로와 일치하는지 확인하세요.
- 백업은 같은 서버 디스크에 생성됩니다. 서버 장애/분실 대비를 위해 암호화된 별도 원격 저장소로 복사하는 정책을 별도로 구성해야 합니다.

6. 복구(주의: 서비스 중단 필요)
- docker compose stop app
- 백업 파일을 확인하고 컨테이너로 전달하거나 /backups에서 직접 사용합니다.
- docker compose run --rm app python /app/restore_db.py /backups/백업파일.sqlite3 --yes
- docker compose up -d app
- curl -fsS https://실제도메인/health
- restore_db.py는 기존 DB의 사전 복구본을 같은 폴더에 남깁니다.

7. 스마트폰/PC 설치
- Android: Chrome으로 HTTPS 사이트 접속 → 설치 안내 또는 브라우저 메뉴의 앱 설치
- iPhone: Safari로 HTTPS 사이트 접속 → 공유 → 홈 화면에 추가
- Windows: Edge/Chrome으로 HTTPS 사이트 접속 → 주소창의 설치 아이콘 또는 메뉴의 앱 설치
- 설치 가능 여부는 브라우저/OS 버전과 HTTPS 상태에 따라 다릅니다.

8. 출시 전 필수 확인
- 실제 운영자/사업자 정보로 약관·개인정보 처리방침 수정 및 법률 검토
- SMTP 인증 메일, 비밀번호 재설정, 알림 메일 실계정 테스트
- Toss 테스트 키로 결제/웹훅/해지/환불 흐름 검증 후 운영 키 적용 및 계약·심사 확인
- 백업 파일을 별도 저장소에 복사하고 복구 리허설 수행
- Android/iPhone/Windows 실기기 설치와 업데이트 테스트

주의: 이 안내서는 배포 절차입니다. 이 ZIP만으로 클라우드 서버/도메인/SMTP/Toss 운영계정이 자동 생성되거나 실제 배포되는 것은 아닙니다.
