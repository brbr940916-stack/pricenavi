가격 추적기 v9 패키지
====================

클라우드 베타는 cloud_app.py이며 Docker Compose + 도메인 + HTTPS 구성으로 배포합니다.

먼저 다음 문서를 읽으세요.
- README_V9_KO.txt: 요금제/관리자 설정
- README_CLOUD_KO.txt: 서버 배포와 이메일 설정
- CHANGELOG_9.txt: v9 변경사항

기존 PC용 프로그램은 START_WINDOWS.bat으로 별도 실행할 수 있습니다.
클라우드 버전 로컬 테스트는 START_CLOUD_LOCAL_WINDOWS.bat을 사용하세요.

주의: PG 결제 연동은 미구현입니다. 관리자 수동 요금제 변경만 제공하며, 실제 결제된 구독으로 간주하면 안 됩니다.
