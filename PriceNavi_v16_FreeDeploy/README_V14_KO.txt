가격 추적기 v14 안내
====================

v14는 v13의 기존 회원·상품·가격 추적·알림·결제 기능을 유지하면서 PWA 설치형 웹앱 지원과 Docker 배포 안정성 개선을 추가한 버전입니다.

주요 추가 기능
- Android 및 데스크톱 브라우저 설치 프롬프트
- iPhone Safari의 공유 > 홈 화면에 추가 안내
- PWA manifest 및 192/512 앱 아이콘
- 서비스 워커의 기본 화면 오프라인 캐시 (API/개인정보 응답은 캐시하지 않음)
- Docker healthcheck와 Caddy 앱 준비 상태 의존성
- 서버 배포/설치 설명: DEPLOY_VPS_PWA_KO.txt

설치 방식 안내
이것은 네이티브 APK/IPA가 아니라 PWA입니다. 실제 도메인과 HTTPS가 연결된 서버에 배포한 뒤 브라우저에서 설치합니다. 별도 앱스토어 등록은 필요하지 않습니다.

기존 기능과 설정
- v13의 .env 설정 및 DATABASE_PATH를 유지합니다.
- 업데이트 시 앱을 중지하고 DB 파일을 백업한 다음 새 파일로 교체하십시오.
- 기존 DB는 additive migration 방식으로 유지됩니다.
- Docker 배포 시 docker compose up -d --build 명령으로 이미지를 다시 빌드하십시오.

주의
- 이 패키지는 실제 VPS에 배포된 상태가 아닙니다. 도메인/DNS/HTTPS 및 서버 계정은 운영자가 준비해야 합니다.
- Android/iPhone 실기기 설치, 실결제, SMTP 발송은 아직 실환경 검증되지 않았습니다.
- 오프라인에서는 저장된 기본 화면만 열릴 수 있으며 로그인·가격 추적·결제·알림은 서버와 인터넷이 필요합니다.
- 약관 및 개인정보 처리방침은 실제 사업자·처리 현황에 맞게 수정하고 법률 검토 후 공개해야 합니다.
