가격 추적기 정식 출시 전 체크리스트 (v13)

[사업자/법률]
- 서비스 이용약관 및 개인정보 처리방침의 [대괄호] 항목을 실제 사업자/담당자 정보로 교체
- 실제 수집 항목, 보유기간, 파기 기준, 결제/메일/호스팅 위탁업체와 국외 이전 여부 확인
- 통신판매·전자상거래 등 사업 형태에 적용되는 신고/고지 의무를 전문가와 확인
- 환불/청약철회, 자동결제 해지, 고객 문의 절차를 결제 화면과 약관에 일치시킴
- 개인정보 보호책임자 및 고객 문의 채널 지정

[서비스/보안]
- 운영 도메인 HTTPS, APP_SECRET, Toss 운영 키, SMTP 인증 정보 설정
- 테스트 결제/자동결제/해지/환불/웹훅을 운영 키가 아닌 테스트 환경에서 우선 검증
- 관리자 계정 MFA 또는 접근 IP 제한 등 추가 보호 적용
- 로그에 비밀번호, 인증 토큰, 빌링키, 결제 비밀키가 기록되지 않는지 확인
- 공개 배포 전 취약점 점검 및 외부 보안 검토

[백업/복구]
- BACKUP_WINDOWS.bat 또는 python backup_db.py로 백업 생성
- 별도 암호화된 원격 저장소에 백업 복사(현재 ZIP은 원격 업로드를 자동 구성하지 않음)
- 복구 연습: 앱 정지 → python restore_db.py 백업파일 --yes → 앱 재기동
- 복구 스크립트는 현재 DB를 .pre-restore-타임스탬프 파일로 먼저 보존
- 복구 후 /health 및 회원/상품/결제 기록 확인

[개인정보 내보내기]
- 로그인 상태에서 GET /api/account/export 요청 시 본인 계정 데이터 JSON을 반환
- 결제 비밀키·세션 토큰·비밀번호 해시는 내보내지 않음

주의: 약관/개인정보 처리방침은 게시용 완성 법률문서가 아닌 운영 초안이며, 실제 운영 실태 및 대한민국 적용 법령에 맞춘 검토가 필요합니다.
