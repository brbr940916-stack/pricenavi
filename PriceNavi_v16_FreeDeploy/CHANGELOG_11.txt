가격 추적기 v11 변경사항
=======================
- v10 cloud_app.py를 기반으로 기존 회원/상품/결제 데이터 구조 유지
- Toss Payments 카드 빌링 인증 및 빌링키 발급 흐름 추가
- 빌링키를 APP_SECRET 기반 Fernet 암호문으로 저장
- 최초 카드 등록 직후 첫 월 구독 결제 처리
- 서버 백그라운드 워커가 30일마다 자동결제 요청
- 사용자 자동갱신 해지 기능 (현재 결제기간은 만료일까지 유지)
- 관리자 운영 대시보드: 회원/유료회원/결제액/활성 구독/실패 결제 통계
- 관리자 결제 내역 조회 및 Toss 전액 환불 API 연동
- Toss PAYMENT_STATUS_CHANGED 웹훅 수신 후 결제 API 조회로 상태 대사
- /health DB 상태 점검, 운영 이벤트 로그
- Docker 이미지에 cryptography 의존성 추가

주의
- 자동결제는 Toss Payments 별도 계약/심사와 자동결제 지원 키가 필요합니다.
- 실제 카드 등록/청구/환불은 가맹점 테스트 또는 운영 키가 있어야 검증할 수 있습니다.
- 결제 실패 시 구독은 past_due로 전환되며 자동 재시도/카드 재등록 UX는 아직 미구현입니다.
- 환불은 관리자 전액 환불만 UI에서 제공하며 부분 환불 UI는 미구현입니다.
- 웹훅은 원본 이벤트를 저장하고 결제 조회 API로 상태를 확인합니다. Toss 콘솔에 /webhooks/toss를 등록해야 합니다.
- 실제 운영 전 PG 계약, 환불정책/약관/개인정보 처리방침, 보안 점검이 필요합니다.
