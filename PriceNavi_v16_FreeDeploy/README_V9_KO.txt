가격 추적기 v9 안내
==================

v9는 v8 클라우드 베타에 요금제/사용량/관리자 기능을 추가한 버전입니다.

요금제 한도(초기 운영 테스트 기준)
- FREE: 상품 5개
- PRO: 상품 100개
- ADMIN: 관리자 계정 전용

관리자 설정
1. .env 파일을 만들고 .env.example을 복사합니다.
2. APP_SECRET에 32자 이상의 무작위 비밀값을 설정합니다.
3. ADMIN_EMAIL에 관리자 계정으로 사용할 이메일을 설정합니다.
4. docker compose up -d --build 로 실행합니다.
5. ADMIN_EMAIL과 같은 이메일로 회원가입하면 관리자 권한이 부여됩니다.
   이미 가입된 계정이라면 서버 재시작 시 init_db가 해당 이메일을 관리자 처리합니다.

관리자 화면
- 로그인 후 관리자 영역에서 사용자와 상품 사용량을 확인할 수 있습니다.
- 사용자별 FREE/PRO를 수동 변경할 수 있습니다.
- PRO는 변경 시점부터 30일로 설정됩니다.
- 요금제 변경은 관리자 전용이며 일반 사용자는 자신에게 권한을 부여할 수 없습니다.

결제 관련 중요 안내
- 실제 카드/간편결제 PG 연동은 아직 포함하지 않았습니다.
- 관리자 수동 PRO 변경은 결제 완료를 뜻하지 않습니다.
- 실제 유료 판매 전에는 PG 가맹점 등록, 결제 승인 API, 웹훅 서명 검증, 취소/환불, 세금/약관/개인정보 처리 절차가 필요합니다.

실행 방법
- 기존 v8과 동일하게 README_CLOUD_KO.txt를 참고하세요.
- 기존 데이터베이스는 v9 실행 시 자동으로 필요한 컬럼이 추가됩니다.

제한
- 서버가 실행 중일 때만 백그라운드 가격 확인이 동작합니다.
- 공개 HTML에서 가격을 읽지 못하는 쇼핑몰/상품은 추적에 실패할 수 있습니다.
- 이메일은 SMTP 설정이 있어야 발송됩니다.
