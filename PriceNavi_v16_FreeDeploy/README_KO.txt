가격 추적기 v7 (Windows)

실행 방법
1. ZIP 압축을 풉니다.
2. Python 3.10 이상을 설치합니다.
3. START_WINDOWS.bat을 더블클릭합니다.
4. 브라우저에서 http://127.0.0.1:8765 가 열립니다.

v7 주요 기능
- Google 쇼핑, 네이버쇼핑, 쿠팡, G마켓, 11번가 검색 페이지 열기
- 상품 페이지 공개 JSON-LD/itemprop 가격 확인 및 앱 실행 중 24시간 주기 확인
- 판매처별 배송비를 포함한 최종 가격 계산
- 모델명/품번, 옵션/구성, 비교 그룹명 입력
- 비교 그룹명 → 모델명+옵션 → 상품명 순서로 비교 그룹 구성
- 배송 포함 가격 기준 최저가 비교
- 목표가에 처음 진입하면 알림 이벤트 저장
- 브라우저 알림 권한 허용 시 목표가 도달 알림 표시
- CSV 내보내기 (모델명, 옵션, 비교 그룹, 가격, 배송비 포함)
- 선택적 API.SH 11번가 검색 및 추적

사용 순서
1. 상품명을 입력하고 쇼핑몰 검색 페이지를 엽니다.
2. 판매 페이지에서 정확히 같은 모델/옵션을 골라 상품을 등록합니다.
3. 모델명/품번과 옵션/구성을 입력합니다.
4. 여러 판매처를 비교하려면 각 등록 항목에 동일한 비교 그룹명을 입력합니다.
5. 배송비와 목표가를 입력합니다.
6. 상단의 '가격 알림 켜기'를 눌러 브라우저 알림 권한을 허용합니다.

중요한 제한
- 쇼핑몰 검색 결과를 무단 자동 수집하지 않습니다. 11번가 API 검색 결과만 프로그램 내부에서 표시합니다.
- 자동 가격 수집은 판매 페이지가 공개 JSON-LD 또는 itemprop 가격 정보를 제공할 때만 동작합니다. 로그인, 옵션 선택, 자바스크립트 렌더링, 봇 차단 페이지에서는 실패할 수 있습니다.
- 배송비는 직접 입력해야 합니다. 판매처의 배송비 변경은 자동 반영되지 않습니다.
- 비교 그룹은 사용자가 입력한 비교 그룹명 또는 모델명/옵션 또는 상품명을 기준으로 합니다. 같은 그룹에 등록한 상품이 실제 동일 상품인지 확인해야 합니다.
- 브라우저 알림은 권한 허용 후 이 화면이 열려 있을 때 표시됩니다. 이메일/문자/카카오 알림은 아직 지원하지 않습니다.
- 자동 확인은 프로그램이 실행 중일 때만 동작합니다. PC가 꺼져 있거나 프로그램을 종료하면 확인하지 않습니다.
- 서버형 상시 운영/클라우드 배포/유료 구독 결제 기능은 구현되지 않았습니다.
- API.SH 연결은 선택 기능이며 키 발급 및 요금/제공량은 제공업체 정책을 따릅니다.
- 데이터와 설정은 프로그램 폴더의 price_tracker.db 및 settings.json에 저장됩니다.

CSV 내보내기로 데이터를 Excel에서 열 수 있습니다. 외부 패키지 설치 없이 Python 표준 라이브러리만 사용합니다.
