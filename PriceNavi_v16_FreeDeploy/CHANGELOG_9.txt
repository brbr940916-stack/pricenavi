가격 추적기 v9 변경사항
=====================

1. 무료/PRO/관리자 요금제 기반
- 무료: 추적 상품 최대 5개
- PRO: 추적 상품 최대 100개
- 관리자: 내부 운영용 무제한 한도
- 요금제 만료 시 무료 한도로 자동 복귀

2. 관리자 기능
- ADMIN_EMAIL 환경변수로 지정한 계정에 관리자 권한 부여
- 사용자 목록, 현재 요금제, 상품 사용량 확인
- 관리자 화면에서 무료/PRO(30일) 수동 변경
- 수동 변경 이벤트 기록

3. 계정 사용량 API
- /api/account 에 계정, 요금제, 사용량, 만료일 표시
- 상품 등록 시 서버에서 요금제 한도 검증

4. 데이터베이스
- v8 기존 users 테이블을 자동 마이그레이션
- 사용자별 데이터 격리 구조 유지

주의
- 실제 PG 결제 연동은 포함하지 않음. 결제사 가맹점 계정, API 키, 웹훅 서명 검증 정보를 받은 뒤 별도 연결해야 함.
- PRO 요금제 활성화는 관리자 수동 처리이며 실제 결제 성공을 의미하지 않음.
- 상품 가격 수집은 공개 HTML 가격 데이터에 의존하며 판매처 차단/옵션/로그인/JS 렌더링 상황에서는 실패할 수 있음.
