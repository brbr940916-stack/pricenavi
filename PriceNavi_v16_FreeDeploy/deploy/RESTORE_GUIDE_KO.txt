가격 추적기 서버 백업 복구 절차
================================
1) 서비스 중지: docker compose stop app
2) 현재 DB 파일과 backups/ 폴더를 별도 보존합니다.
3) 복구할 백업을 컨테이너가 접근 가능한 경로에 둡니다. 예: /data/backups/price_tracker_YYYYMMDDTHHMMSSZ.sqlite3
4) 컨테이너에서 복구 실행: docker compose run --rm --no-deps app python /app/restore_db.py /data/backups/파일명.sqlite3 --yes
   주의: 위 명령의 파일명은 실제 백업 파일명으로 바꾸고, 반드시 서비스 중지 상태에서 실행하세요.
5) 서비스 시작: docker compose up -d
6) 확인: docker compose ps 및 https://실제도메인/health

복구 전에 현재 데이터베이스의 별도 사본을 확보하고, 백업 파일의 출처와 날짜를 확인하십시오.
