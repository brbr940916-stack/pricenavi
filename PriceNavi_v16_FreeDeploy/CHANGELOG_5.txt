가격 추적기 v5 변경사항
- 상품명 하나로 Google 쇼핑, 네이버쇼핑, 쿠팡, G마켓, 11번가 검색을 각각 열 수 있는 통합 검색 영역 추가
- 11번가 API 검색 결과를 가격 오름차순으로 정렬해 최저가 후보부터 표시
- 기존 URL 가격 추적, 가격 기록, 목표가, CSV 내보내기 기능 유지

주의
- 여러 쇼핑몰의 검색 결과를 한 화면에 자동 통합 수집하는 기능은 포함하지 않음. 각 쇼핑몰 검색은 해당 사이트에서 열리고, 11번가 API 검색 결과만 프로그램 안에 표시됨.
- 검색 사이트의 화면 구조, 로그인, 지역/회원별 가격, 배송비 및 쿠폰 조건에 따라 실제 구매 가격은 달라질 수 있음.
