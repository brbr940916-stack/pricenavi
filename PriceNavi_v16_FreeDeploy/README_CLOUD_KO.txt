가격 추적기 클라우드 베타 v11
============================

구성
- 이메일/비밀번호 회원가입 및 로그인
- 사용자별 상품·알림 데이터 분리
- FREE 5개 / PRO 100개 상품 한도
- 관리자 사용자/요금제 관리
- 서버 백그라운드 가격 확인 및 SMTP 목표가 알림
- 배송비 포함 목표가 비교
- Docker + Caddy HTTPS 배포
- Toss Payments 카드 단건 결제 및 선택형 자동결제(별도 빌링 계약 필요)

배포 (Ubuntu VPS 예시)
1. 도메인의 A 레코드를 서버 IP로 연결합니다.
2. 서버에 Docker 및 Docker Compose 플러그인을 설치합니다.
3. 이 폴더에서 .env.example을 .env로 복사합니다.
4. APP_SECRET을 32자 이상의 무작위 비밀값으로 변경하고 DOMAIN에 실제 도메인을 입력합니다.
5. 이메일 알림을 사용할 경우 SMTP 설정을 실제 메일 서비스 값으로 변경합니다.
6. TCP 80/443 포트를 허용하고 docker compose up -d --build 를 실행합니다.
7. https://실제도메인/health 에서 status=ok, database=ok 응답을 확인합니다.

결제 테스트
- README_V10_KO.txt를 읽고 Toss 테스트 클라이언트 키/시크릿 키를 .env에 설정합니다.
- PUBLIC_BASE_URL은 Caddy HTTPS 도메인과 정확히 일치해야 합니다.
- 결제 기능은 테스트 키와 HTTPS URL이 모두 있을 때만 활성화됩니다.
- 운영 키로 교체하기 전에 테스트 결제 승인/실패 흐름을 확인하세요.

중요한 제한
- v11은 단건 결제와 선택형 자동결제, 관리자 전액 환불, 웹훅 상태 대사 및 운영 대시보드를 포함합니다. 자동결제는 별도 빌링 계약이 있어야 합니다. 자세한 내용은 README_V11_KO.txt를 확인하세요.
- 실제 PG 가맹점 승인 및 도메인 등록, 약관/환불정책/개인정보 처리방침, 세무·사업 관련 의무를 확인해야 실제 판매할 수 있습니다.
- 가격 정보는 판매처가 공개한 HTML 메타데이터에서만 추출합니다. 로그인/옵션/자바스크립트가 필요하거나 자동 접근을 막는 페이지는 실패할 수 있습니다.
- 서버가 중단되면 백그라운드 가격 확인도 중단됩니다.
- 단일 인스턴스 + SQLite 기반 베타입니다. 트래픽이 늘면 PostgreSQL, 작업 큐, 속도 제한, 백업/복구, 모니터링을 추가해야 합니다.
- .env, 데이터베이스, SMTP 비밀번호, Toss 시크릿 키를 공개 저장소에 올리지 마세요.

로컬 실행
- Python 3.10 이상
- APP_SECRET 환경변수 설정 후 python cloud_app.py
- 브라우저에서 http://localhost:8080
- 로컬 실행은 결제 HTTPS 조건을 충족하지 않아 결제 기능이 기본 비활성화됩니다.
